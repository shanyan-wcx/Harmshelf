# 适配播放页弹出面板文字颜色

## Goal

让全屏播放页的弹出面板文字颜色跟随当前封面主色明暗，使用播放页控件已经采用的深浅色配色，避免面板标题和内容仍使用固定的系统默认颜色。

## Requirements

- 仅修改全屏播放页 `Play.ets` 中的书签、倍速、睡眠定时、章节、编辑书签面板。
- 面板标题、正文、选项、章节/书签信息及输入框文字，使用与播放页控件一致的 `playColorPalette` 主色/次级色。
- 封面主色切换到浅色或深色对比方案时，已打开或重新打开的面板文字颜色应同步切换。
- 保留现有面板材质、尺寸、圆角、字体大小、间距、选中态、交互回调和滚动行为。
- 不修改迷你播放条、非播放页面板或其他页面的文字配色。

## Acceptance Criteria

- [x] 五个全屏播放面板的标题颜色与播放页主标题使用同一主色。
- [x] 面板内主内容文字使用播放页主色，时间/占位等次级信息使用播放页次级色。
- [x] 倍速、睡眠、章节的选中与未选中选项都能在浅/深封面背景下清晰显示。
- [x] 编辑书签输入框的已输入文字和占位文字均跟随对应主色/次级色。
- [x] 现有面板打开、关闭、选择、编辑和播放操作不受影响，ArkTS 编译通过。

## Constraints

- 优先复用现有 `playColorPalette`，不新增依赖或第二套颜色判断逻辑。
- 鸿蒙 `SheetTitleOptions` 不提供字体颜色属性；标题颜色需通过 `SheetOptions.title` 的 `CustomBuilder` 实现，并保持原生标题布局观感。
