# 搜索结果沉浸光感列表样式

## Goal

将搜索页面的书籍和播客搜索结果从“分割线列表”改为独立的沉浸光感圆角矩形项，提升结果项的层次感，同时保持现有列表节奏和内容点击行为。

## Background

- `pages/Search.ets` 当前通过 `List.divider` 显示分隔线，书籍和播客结果的内容结构重复。
- 每个结果项当前高度由 64vp 封面决定，首项顶部避让和其他项上下 `10vp` 间距已经形成现有列表节奏。
- `utils/Component.ets` 已有共享 `ImmersiveActionButton`，内部使用原生 `HdsTabs` 沉浸光感材质；其手机/平板默认半圆形圆角不适合搜索结果卡片，因此需要支持调用方指定固定圆角。

## Requirements

- 移除搜索结果 `List` 的分割线，不再渲染 `List.divider`。
- 书籍和播客的每个搜索结果项均使用共享 `ImmersiveActionButton` 作为可点击的沉浸光感容器。
- 搜索结果项统一为圆角矩形，固定使用 `8vp` 圆角，不随设备类型变为胶囊形。
- 保持搜索项内容、封面尺寸、左右 `20vp` 内容边距、首项顶部避让和现有上下间距不变；分割线移除后，项与项之间的视觉间隔仍保持当前列表节奏。
- 保留点击搜索项进入媒体详情页的行为，不改变搜索请求、加载状态和无结果状态。
- 扩展 `ImmersiveActionButton` 的圆角配置时保持现有调用方行为不变；未传入配置的调用方继续使用当前设备适配圆角。

## Acceptance Criteria

- [x] 搜索结果列表不再显示分割线。
- [x] 书籍和播客的每个结果项均显示沉浸光感背景，且为统一的 `8vp` 圆角矩形。
- [x] 搜索项之间的上下间距与修改前一致，首项顶部避让和末项底部避让不变。
- [x] 结果项内容位置、封面尺寸和左右边距不变。
- [x] 点击任意结果仍进入对应的媒体详情页。
- [x] 现有沉浸光感按钮调用方外观和交互不发生变化。
- [x] `git diff --check` 和 HarmonyOS ArkTS 构建检查通过。

## Key Decisions

- 复用共享 `ImmersiveActionButton`，不在搜索页复制 HdsTabs 沉浸材质实现。
- 为共享按钮增加可选固定圆角参数，搜索项传入 `8vp`；默认值仍走现有设备类型圆角规则。
- 通过保留现有 `ListItem` 的上下 margin，并将左右 `20vp` 作为按钮容器边距，移除分割线后维持原有列表节奏。

## Out of Scope

- 不调整搜索栏、标题栏、搜索接口、结果排序或结果数据结构。
- 不新增作者、系列等当前未展示结果类型的列表项。
- 不修改项目详情页、剧集详情页或其他页面的沉浸光感按钮。

## Risks / Deferred Checks

- 原生 HDS 材质的阴影和圆角在不同设备上的最终视觉效果需要真机或模拟器确认；代码阶段通过构建和静态检查验证。
