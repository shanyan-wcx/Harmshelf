# 修复搜索项圆角与间距

## Goal

让搜索结果改用可控的手动圆角矩形卡片，提供透明毛玻璃、微亮边框和悬浮阴影，同时保证高度、圆角和内边距在各设备上真实生效。

## Background and confirmed constraints

- 当前搜索页书籍和播客结果均使用共享 `ImmersiveActionButton`，但按钮的高度、圆角和内边距被 HdsTabs 原生悬浮材质接管，调用参数无法可靠控制视觉结果；播客添加页结果项仍使用分割线布局；项目详情页章节/音轨列表仍使用透明行和外层矩形边框。
- 官方 `HdsTabsFloatingStyle`（API 6.1.0/23）没有圆角字段；继续修补沉浸按钮不能保证搜索卡片形状，因此本次明确放弃该方案。
- 项目已有普通 `Row`/`Button` 使用圆角和 `.onClick()` 实现可控卡片。
- 项目已有 `backgroundBlurStyle(BlurStyle.COMPONENT_THICK)`、`.border({ width, radius, color })` 和 `.shadow(...)` 的 ArkUI 写法；本次使用 SDK 提供的透明卡片背景资源叠加毛玻璃，不使用不透明背景色破坏模糊效果。
- 当前结果项外层左右边距为 20vp，非首项顶部和非末项底部均为 10vp。

## Requirements

1. 移除搜索结果对 `ImmersiveActionButton` 的引用，搜索页书籍/播客分支和播客添加页结果项都使用普通可点击 `Row` 卡片。
2. 卡片使用 `backgroundBlurStyle(BlurStyle.COMPONENT_THICK)` 和系统主题自适应的 `sys.color.ohos_id_color_card_bg` 形成可区分的卡片背景；圆角固定为 12vp，高度固定为 80vp。
3. 卡片使用 0.5vp 的主题自适应细边框模拟沉浸光感高亮，并使用系统 `ShadowStyle.OUTER_DEFAULT_XS` 形成轻柔悬浮阴影；卡片自身不裁切阴影。
4. 卡片内部内容左右各保留 8vp，与 80vp 卡片中 64vp 封面的上下留白一致；外层现有左右 20vp 页面边距继续保留。
5. 非首项顶部和非末项底部间距改为 8vp；首项顶部标题栏避让和末项底部安全区避让保持不变。
6. 深色模式下仍能看清白色高亮边框和悬浮阴影；不修改搜索项原有文字颜色。
7. 不改变搜索结果数据、点击跳转、封面尺寸、文字截断和滚动行为。
8. 播客添加页保留原有获取 Feed、弹出确认面板和添加逻辑，只替换结果项卡片外观并移除分割线。
9. 项目详情页章节和音轨列表保留表头 36vp、数据行原有上下内边距、列表高度和点击行为；每组列表变为一个大卡片，表头和数据行统一显示卡片背景，滚动内容不得超出卡片边界。

## Out of scope

- 不修改其他页面的 `ImmersiveActionButton`，不新增依赖。
- 不调整搜索栏、标题栏、搜索逻辑或结果数据模型。
- 不保留搜索结果的原生沉浸材质；本次目标是几何尺寸和圆角可控。

## Acceptance Criteria

- [ ] 书籍与播客搜索结果均为普通 80vp 高、12vp 圆角矩形卡片，内容距离卡片左右边缘 8vp，页面外侧边距仍为 20vp。
- [ ] 卡片可见透明毛玻璃背景、白色高亮边框和向外扩散的悬浮阴影，阴影没有被卡片自身裁切。
- [ ] 搜索项之间的视觉间隔小于当前约 20vp；首项顶部和末项底部避让未被削弱。
- [ ] 搜索结果不再显示为胶囊，12vp 圆角由普通卡片容器直接控制；深浅色模式均使用与页面相邻层级的系统背景色，白色边框和阴影仍清晰可见，文字颜色保持原样。
- [ ] 点击任意搜索结果仍进入对应媒体详情页，列表滚动不受影响。
- [ ] 播客添加页结果项使用相同的 80vp 卡片样式，点击后仍正常获取 Feed 并打开确认面板。
- [ ] 项目详情页章节和音轨列表各自为一个 30vp 圆角大卡片，圆角为上方 60vp 操作按钮高度的一半；表头和数据行统一使用卡片背景；卡片有细边框和轻阴影，滚动内容被卡片圆角裁切，原有尺寸和交互不变。
- [ ] `devecocli` debug build 通过，且变更范围只包含本任务相关文件。

## Open questions

- 无。间距采用最小调整方案：每项顶部/底部从 10vp 降到 8vp。
